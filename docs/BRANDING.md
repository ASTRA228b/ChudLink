# Branding assets

The current ChudLink logo is **assets/branding/chudlink-logo-v2.png**, remade at the user's request as a simpler interlocking circuit-link mark on opaque near-black. Windows and Android use derived launcher/icon sizes from that file. The first mark is retained at assets/branding/chudlink-mark.png as a superseded draft.

The original ChudGPT logo is preserved unchanged from [the landing-page logo](https://chudgpt-landing.vercel.app/chudgpt-logo.png), retrieved 2026-11-27, at assets/branding/chudgpt-logo-original.png. It provides ecosystem attribution. The decorative overview concept art is assets/branding/chudlink-companions.png; it is not a screenshot.

All generated assets used the **built-in imagegen tool**, without a separate API key. scripts/brand-assets.ps1 converts the selected PNG into platform ICO/PNG sizes without generative changes. No secrets or user photographs were used.

## Production logo refinement prompt

Use case: logo-brand. Edit target image: the ChudLink interlocking chain-link mark in image 1. Refine it into a finished application icon. Preserve the diagonal two-link silhouette and centered square composition, but make every edge completely clean and smooth, with consistent geometry. Use one uniform solid vivid lime #C6FF2E for both links, with no gradient, no grain, no texture, no speckles, no light effects. Make the two little terminal holes perfectly circular, filled with exactly the same near-black as the background. Background must be an OPAQUE UNIFORM near-black #0A0E0B, including all negative space. NO transparency anywhere. Remove all debris and stray pixels inside and outside the links. Separate the links at their crossing with clean narrow near-black gaps to clarify interlocking, rather than shading. Keep the mark within the central 60% of the square so it is safe within a circular Android icon mask. No text, no wordmark, no added objects. Professional restrained software logo, flat vector-like finish.

## Remade logo exploration prompt

Create an entirely NEW, much cleaner ChudLink mark, not a copy of the original. ONE compact symmetrical icon: two interlocking rounded rectangular chain links arranged diagonally, with exactly two tiny circular circuit terminal cutouts incorporated into the link ends. The negative space between the links subtly evokes connected devices. Visually simple, mathematically precise, consistent thick stroke weight, rounded corners, flat single vivid lime #C6FF2E with near-black negative space and no white dots. Premium software/hardware brand, equally legible at 24px and 1024px. Square canvas with icon centered and occupying 62% of the canvas, generous clean transparent margin for Android adaptive masks. Sharp vector-like raster edges and smooth antialiasing. No grain, no pixel debris, no glow, no shadows, no gradients, no 3D, no letters, no wordmark, no text, no presentation board, no background. Transparent background with a fully clean alpha channel.
